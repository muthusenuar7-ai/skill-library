How import works

  • Folders in a ZIP become categories; otherwise the guide's own Domain line is used. You can change every category before saving.
  • A folder containing SKILL.md is a skill package: its other files are kept as supporting files.
  • Duplicates (same content, reference, slug or title) are skipped unless you choose Replace or Import as new.
  • Unsafe paths, system files, oversized or encrypted entries are rejected and listed. Nothing in a file is ever run.
